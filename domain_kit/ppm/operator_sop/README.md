# Operator SOP layer (PPM layer 2)

HotelOps will **refuse** a PPM work order when:

1. The jurisdiction has no statutory-floor row for the asset (fire, lift,
   pressure vessel, water hygiene), or
2. No **named** operator SOP body is supplied, or
3. The caller asks the platform to emit a generic frequency table as
   authoritative.

Frequencies are **never estimated** from the Domain Encoding Sheet (Class B).
Refer to the named operator SOP and the statute text. An empty file in this
folder does not count.

Construction PM systems (Aconex, Procore, BIM) are out of scope.
